No key yet?

Run one of these in the Bridge folder:

Just trying it: demo mode, opens signed in
npm run dev
First time: set up and print an admin key
npm run bridge -- init
Another key
npm run bridge -- keys create --label me --scope admin,paper

Lost your key? You do not need it here: open the Bridge again from its shortcut, or run mc-bridge open (in the Bridge folder: npm run bridge -- open). The dashboard then opens already signed in.

Local dashboard, this computer only. The key stays in this browser tab and is forgotten when you close it.
