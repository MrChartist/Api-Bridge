Sign in with your admin key

The key was printed once when you ran the setup. It stays in this browser tab and is forgotten when you close it.

No key yet?
  1. In the Bridge folder, run npm run bridge -- init (first time), or
  2. npm run bridge -- keys create --label me --scope admin,paper

Lost your key? You do not need it here: open the Bridge again from its shortcut, or run mc-bridge open (in the Bridge folder: npm run bridge -- open). The dashboard then opens already signed in.
